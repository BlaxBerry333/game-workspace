# 画面适配

项目的 README 和它链接的文档跟这里冲突时先问我。

## 要支持的范围

| 项目 | 范围 |
|---|---|
| 窗口比例 | 16:9 到 32:9（带鱼屏）都铺满，不加黑边。日常开发的窗口是 1920×929（约 2.07:1） |
| 最小窗口 | 1024×600，宽高比至少 4:3。更小、更窄时不显示游戏，只显示「窗口太小」的提示，不做小窗口、竖屏、手机的适配 |
| 屏幕大小 | 笔记本到 4K、5K |
| 浏览器 | Chrome 为主，之后实测 Firefox、Safari |

## 3D 画面

- 竖直视野固定（`PerspectiveCamera.fov` 本来就是竖直方向的），窗口越宽，左右看到的越多
- 比 16:9 窄时，按 16:9 时的水平视野反算竖直视野，保证左右不比 16:9 少
- 每帧渲染的像素总数不超过 2560×1440（约 369 万）。屏幕更大时降低绘制分辨率，由 CSS 拉伸到窗口大小。像素比的上限是 2

## UI

- 按 1920×1080 设计
- 尺寸一律用 `rem`。根字号按窗口高度缩放：1080 高时 16px，限制在 12px–32px（`clamp(12px, 100dvh * 16 / 1080, 32px)`）
- HUD 放在画面中间的安全区里：宽度取「窗口宽」和「窗口高 × 21/9」中较小的那个，居中。带鱼屏上安全区两边不放 HUD
- 文字不做成图片，换语言、缩放时才清晰

## 背景图和 2D 美术

- 不拉伸：背景用 `object-fit: cover` / `background-size: cover`；必须完整显示的用 `contain`；不用 `fill`
- 按 32:9 的比例画，重要的内容（标题、人物）放在中间 16:9 的区域里，也就是宽度的中间一半。左右延伸出去的只画风景，带鱼屏能看到更多，16:9 只显示中间
- 能拆层的就拆层（天空、远景、近景、人物），每层分别定铺满方式和对齐位置
- 准备 1080、1440、2160 高三档，用 `image-set()` 或 `srcset` 让浏览器按屏幕挑。格式用 AVIF 或 WebP

## 验证

改了画面或 UI 之后，在这些窗口尺寸下截图看一遍：

| 尺寸 | 代表什么 |
|---|---|
| 1920×929 | 日常开发 |
| 1920×1080 | 16:9 |
| 2560×1080 | 21:9 |
| 5120×1440 | 32:9 带鱼屏 |
| 3840×2160 | 4K |
| 1280×720 | 小窗口 |
| 1024×768 | 4:3，能用的最窄比例 |
| 1024×600 | 最小窗口 |
| 1023×600、1024×599、1024×1024 | 该显示「窗口太小」的提示 |
