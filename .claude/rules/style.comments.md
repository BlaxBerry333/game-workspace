# 注释

- `#` 注释只用分隔框写，不写散的、行内的注释。标题一行，需要时再加一两行说明
- 只写代码看不出来的东西，不写废话、不复述代码

  ```
  # ============================================================
  # 标题
  # 说明
  # ============================================================
  ```
